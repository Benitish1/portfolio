Dataset Request Desk

An internal platform that replaces request spreadsheets: clients ask for robot-data episodes, operators match them from the recording library, and every handover is logged.

  • FastAPI + PostgreSQL 16 with Alembic migrations, running serverless on Vercel with Neon.
  • Client and operator roles with per-client isolation, analytics and CSV import.
  • Dependency-free single-page UI served by the API.

One-click demo accounts on the sign-in page: no sign-up needed.

About me

Software programmer, from interface to infrastructure

I'm a graduate of Rwanda Coding Academy, where I studied Software Programming and Embedded Systems.

I enjoy working across the whole development process: shaping interfaces and mobile experiences, writing the backend services and APIs that power them, and designing the databases underneath. Most of my recent work has been in React Native with Expo, alongside web projects in React and Next.js with Spring Boot, Node.js and Python backends.

My embedded systems training means I'm also comfortable when software has to talk to hardware — microcontrollers, sensors and MQTT messaging. What draws me to a project is a real problem to solve, whether that's community safety, property rentals or fire-safety compliance.
